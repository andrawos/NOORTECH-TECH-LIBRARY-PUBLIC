# Responsive Landing Page Template

**Version:** 1.0.0  
**Status:** Original starter template; visual/browser QA pending.  
**License:** MIT for the files in this template.  
**Dependencies:** None. Vanilla HTML, CSS and JavaScript.

## Files
- `index.html` — semantic landing page structure and editable placeholder copy.
- `landing.css` — responsive layout and design tokens.
- `landing.js` — mobile navigation and dynamic copyright year.
- `LICENSE.md` — MIT license.

## Sections
Header/navigation, hero, trust strip, three feature cards, mission statement, contact CTA and footer.

## Setup
Open `index.html` directly in a browser, or copy the four files into a static website directory. Replace all placeholder brand text, claims, contact details and email address before publishing.

## Customization
Edit the CSS variables at the top of `landing.css` to change the navy/blue/gold palette. Update the content in `index.html`; retain descriptive link labels and meaningful heading order.

## QA notes
- Responsive breakpoint: 760px.
- Includes skip link, navigation label, mobile menu expanded state, semantic landmarks and reduced-motion preference.
- No external fonts, image URLs, tracking scripts or third-party packages.
- The hero artwork is CSS-only and can be replaced with licensed project imagery.
- Test keyboard navigation, mobile menu behavior, contrast, content overflow and current Chrome/Firefox/Safari/Android Chrome before production.
- Replace `hello@example.com` and all placeholder copy before public use.

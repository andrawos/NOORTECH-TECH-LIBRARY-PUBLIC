Accessibility notes

These samples are decorative and use aria-hidden="true"; each sample also has a visible text identifier.

In a real control, provide an accessible name on the button/link (for example, aria-label="Search") or pair the icon with visible action text. Do not rely on the icon shape alone.

For production, verify 16px legibility on the actual target device. A 24px or larger icon is preferable for common interface controls where space allows.
